# 单人语音通话界面

本次仅调整单人语音通话的呈现和控件位置，沿用原有通话状态、识别、合成、消息发送、重试、接听、拒绝、挂断与缩小回调。

- 保留大圆头像（无头像时显示姓名首字）及下方角色姓名，合并顶部重复姓名。
- 姓名下显示时长和状态；底部圆形功能键配文字说明，红色挂断键居中单独一行。
- 用户与角色字幕均为半透明黑色圆角气泡，白色文字；长对话保留滚动。
- 文字输入框改为正常文档流排列，避免覆盖最新字幕；小高度容器收紧布局。
- 音量控件复用 `CallVolumeControl`，新增内联呈现方式，沿用真实音量设置逻辑；其他通话界面仍使用原有位置。
- 通话字体使用本地随包分发的寒蝉全圆体 Regular（约 5.9 MiB），仅在使用该字体时加载；完整许可证位于 `public/fonts/call/OFL.txt`。参考图未注明字体名，因此采用相近风格，并非声称识别出同款字体。

只借鉴实际适用的通话视觉层次。界面按钮均对应现有能力，没有加入无实现的通讯录、合并通话或拨号盘按钮。

## 本地预览

开发服务器运行后打开 `http://localhost:3001/dev/voice-call`，预览复用实际的 `VoiceCallView` 与样式。预览中的人物和字幕为固定样例，操作仅改变预览状态，不使用真实角色数据、不申请麦克风、不调用语音或大模型接口。生产环境此路由返回 404。

预览页顶部提供「文字输入」「语音待机」「正在说话」切换，用于查看对应外观。「正在说话」展示 Android 按住录音时的绿色麦克风与「松开发送」提示，不伪造录音中的即时转写；该模式实际在松手后才提交音频识别。

按用户要求，不运行真实通话、接口、录音或自动化功能测试；通过代码审查、TypeScript 静态检查和开发页面外观查看确认修改。

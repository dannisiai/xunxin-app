# 系统状态栏与页面顶部背景

用户看到的时间、信号、电量属于 Android 系统状态栏。应用标题仍在系统栏下方，二者可以使用连续的背景。

## 本次修复

- 原生窗口原本已经启用 edge-to-edge、透明系统栏并关闭系统强制对比色。本次保留这部分设置。
- 旧逻辑只提取正文背景作为安全区底色，公共标题栏另有 55% 的半透明背景，因此浅灰正文与更浅的标题栏之间出现色带。
- 公共外壳的非交互背景层现在在预留的顶部区域绘制当前可见标题栏的背景和 backdrop-filter。正文底色与标题栏覆盖层分别保存，避免每次更新又把半透明颜色叠加到自身。
- 顶栏通过实际布局和命中顺序选择，忽略隐藏的常驻应用窗格和被覆盖的旧页面。设置、资源、外观、聊天和其他使用公共标题栏的页面共用此逻辑；阅读、音乐等自定义 header/topbar 也可被识别。没有可识别标题栏时沿用当前页面底色。
- 顶部图标明暗与 PWA theme-color 使用标题栏和正文合成后的亮度，底部导航图标继续依据正文底色单独选择明暗，适配浅标题栏搭配深色内容的情况。旧桥接方法仍可用，新接口同样校验可信页面并在 UI 线程执行。切换页面、标题栏样式、主题或原生窗口几何时重新计算。
- 背景延伸层不接收点击，安全区和灵动岛的占位仍由原有外壳处理，返回按钮等交互内容不会上移到系统时间/摄像头位置。
- 图片亮度取样最多缓存 16 个 URL 的结果，失败不保留缓存；异步结果保留版本检查，旧页面不能覆盖新页面的配色。

## 范围和验证限制

这是背景连续性修复，不会隐藏真正的系统时间、信号和电量。普通纯色、半透明公共标题栏可以沿用相同的底色与覆盖层；图片、复杂渐变、滚动毛玻璃、双栏中左右背景不同的页面仍需真机确认，不能声称已经逐像素一致。独立窗口及第三方 HTML 不承诺自动接入。

本次只进行源码语法、类型、CSS 和镜像一致性静态检查，不运行应用、功能测试或模拟器。APK 编译成功也不等于真机视觉效果已经确认。

参考：[Android 官方 edge-to-edge 与安全区说明](https://developer.android.com/develop/ui/views/layout/edge-to-edge)。

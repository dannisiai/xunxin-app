# 默认免费加速下载

> 历史方案，仅供旧版本参考。当前 OTA 请使用[日本服务器部署流程](android-ota-updates.md#日本服务器部署)。

从 1.0.1（内部版本号 24）起，Android 更新安装包默认使用 `https://gh-proxy.com/` 加速公开 GitHub Releases 资源。此公益服务没有可用性或速度保证，失败时自动尝试原始 GitHub 地址。

更新清单继续从既有的 GitHub 固定通道获取，不经第三方代理。发布脚本自动把清单中的 APK 地址及发布说明的首个下载链接改为加速地址。每个新 Release 使用固定资产名 `xunxin.apk`，因此 README 的 latest 下载链接在后续发布时无需修改。

Android 同时兼容清单中的原始 GitHub Release 地址和加速地址，仅对明确的公开 GitHub Release 路径应用此前缀。其他自建下载地址沿用原址。单次下载先尝试加速源，网络错误、错误响应或安装包校验失败时尝试原始源；用户取消、磁盘写入错误、存储空间不足不触发备用下载。

断点元数据记录实际下载源。切换源时丢弃该次 OTA 候选文件和旧验证器，从零下载，避免混合不同源的数据；同源暂停后继续保留断点。摘要、真实 APK 数字签名、包名、版本和当前已安装签名的检查保持不变。

本机发布使用 `scripts/publish-android-local.py`，参数与原本机发布工具一致：`--artifacts`、`--source`、`--signing-dir`、`--java-home`、`--build-tools`。签名私钥及密码只供本机签名进程读取，发布到 GitHub 的是签名后的 APK 与公开清单。

已安装的 1.0.0 也会使用新清单提供的加速 APK 链接；安装 1.0.1 后获得原生备用源回退能力。此前旧仓库版本仍需先手动迁移到新仓库版本。

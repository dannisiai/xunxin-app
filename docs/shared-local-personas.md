# 本机共用人设存档

按设备所有者要求，所有登录账号自动读取同一份本机人设文件，不按账号区分。这是对人设资料共享范围的明确调整：聊天记录、登录会话、云端凭证和 API 密钥仍保留原有账号范围。

Android 新壳在主共享存储的 `Documents/XunxinLocalArchive/shared-personas.json` 保存角色卡（含内嵌头像）、角色画布素材、角色版本、角色世界分组和用户身份（含身份头像）。这些字段采用固定白名单，不导出其他配置或登录凭证。头像如使用第三方链接，仍取决于原链接可用性；data URL 图片完整保存。当前不包含聊天、主题素材库、音乐、书籍及其他多媒体数据库。

用户不选择文件夹。Android 11 及以上需在系统设置授予“所有文件访问”权限；旧版 Android 使用共享存储权限。首次安装和卸载重装后均须授权，App 无法自行绕过系统授权。实际访问只使用上述固定目录与文件，不遍历手机其他目录。Google Play 对“所有文件访问”有额外发行限制，加入权限声明不代表能通过商店审核。

账号验证完成后，界面在打开桌面和启动后台服务前检查文件：

1. 无存档：保存当前 App 内已有的人设资料，建立共用文件。
2. 有有效存档且内容有变化：检查格式、白名单、SHA-256 和资料结构，写入本机后重新载入页面刷新缓存。
3. 首次接入时合并该账号原有的人设，避免空档覆盖既有人设；同 ID 优先保留更新时间更晚的版本，无法判定时间时共用文件优先。后续以共用文件为准，删除操作也会传播。
4. 损坏、不完整、超过 32MB 或发现文件冲突：阻止覆盖并显示错误。用户可重试或本次继续只用 App 内资料。

人设和身份资料变更后约 1.5 秒自动保存；界面运行时另有一分钟兜底检查。文件分块传输，先写完整临时文件再提交，保留 `shared-personas.previous.json` 上一版。写入期间其他进程修改主文件时会停止覆盖。立即卸载、强杀、断电或权限中断仍可能使最新一次未完成的变更尚未写出；不得将此功能描述为每个时刻的零丢失保证。

共享文件不在应用专属目录中，正常卸载不会由 App 删除；App 没有删除共用目录的卸载操作。用户清理文件、恢复出厂设置或设备损坏仍可能导致丢失。本机公共文件是明文，SHA-256 用于检查完整性，不是加密或所有权证明。所有账号看到相同人设是本功能的预期行为。

数据管理页提供“扫描并载入本机存档”入口，便于重新授权和重新检查。不支持原生接口的旧 APK 与网页不启用自动外部文件访问，需要重新构建安装新壳。此前已卸载、且未保存过此文件的资料不会被该功能找回；现有 ZIP 备份仍需使用原导入功能。

# 账户凭证中的语音模型

入口位于设置 → 账户凭证 → 选择模型下方的「语音模型」。新账户默认关闭；开启后显示原有语音编辑器，包含服务商、接口地址、密钥、模型、音色、试听与服务商支持的音色克隆配置。

可新增多个语音方案，并在「使用的语音方案」中选择当前账户的默认方案。聊天、通话与回复播报的语音绑定统一使用该方案；关闭开关会停用配置解析并收起编辑器，已保存的方案仍会保留，再次开启可继续使用。

自定义 TTS 不显示音色 ID 输入框，也不要求填写音色 ID。Qwen3-TTS Base 的参考音频、参考文本会随合成请求发送；无需额外申请音色 ID。移除本地参考音频后仍使用服务器的默认音色配置；服务端需要支持这一用法。

开关、方案与选中项按 Sub2API 账户保存，不读取或覆盖原有本地模式的语音方案。语音服务仍使用编辑器中配置的服务商接口；文本模型的账户计费代理与这套语音服务配置分别处理。

实现复用 `VoiceSettings` 的嵌入模式；账户设置与有效语音绑定由 `lib/cloud-voice.ts`、`lib/cloud-account.ts` 和 `lib/settings-storage.ts` 管理。`scripts/test-cloud-voice-settings.cjs` 验证默认关闭、关闭保留、账户隔离、绑定解析、删除方案及本地模式兼容性。

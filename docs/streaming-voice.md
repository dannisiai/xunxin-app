# 流式语音回复与试听

一起看抖音、小红书的语音回复，以及设置页的试听，默认请求完整音频。一起看读取角色实际绑定的方案；试听使用当前编辑的方案。旧方案保留原有的「语音合成」设置，现在可以在方案编辑页查看和修改。

已确认服务支持裸 PCM 时，可以在方案编辑页选择流式协议。vLLM-Omni 模式发送 `stream: true`、`response_format: pcm` 和 `stream_format: audio`；其他兼容裸 PCM 模式不附加 vLLM 专用参数。两种模式都保留 Qwen3-TTS Base 的参考音频参数。裸 PCM 按单声道 16 位播放，读取服务给出的采样率和声道。服务若返回 WAV、MP3 等完整文件，会复用同一次响应做文件播放。SSE 响应会明确提示切换协议。

流式试听使用 Web Audio；安卓一起看使用带有界缓冲的 AudioTrack，完整音频则交给 MediaPlayer。音频焦点暂时丢失时，安卓保留当前播放位置和缓冲，焦点恢复后继续。永久丢失焦点时停止并提示，可手动重播已有文件或重试。

安卓播放完成后可重播本机缓存，不再次调用模型。中途停止会取消未完成的请求；流式失败后手动重试会改用完整音频，不自动发起第二次合成。完整对话保留可操作的失败提示。

WAV 解析与裸 PCM 读取均由 `lib/tts-audio-stream.ts` 处理；Android 实际播放在 `CompanionPcmStream.kt`，新原生能力需要安装新版 APK。

1.0.2 起，安卓本地壳的 Qwen 请求先交给 App 自带的本机 Node 服务，再由该服务连接用户配置的语音接口。该路由仅在 Android 本机运行环境启用，受既有安装会话 Cookie 和账号门禁保护；网站部署不开放此代理。参考音频、密钥和文字仍只发往用户配置的接口，不经过额外云端中转。

请求和本机代理的合成总超时为 240 秒。安卓预备阶段额外留出 5 秒用于桥接，收完流后另行等待播放队列清空。仍保留 TLS 校验、响应大小限制、背压和取消处理。

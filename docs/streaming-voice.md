# 流式语音回复与试听

一起看抖音、小红书的语音回复，以及语音模型配置页的「流式试听合成音色」，共用 Qwen3-TTS 的流式合成请求。

Qwen3-TTS Base 继续使用上传的参考音频克隆音色，请求包含 `stream: true` 与 `response_format: pcm`。接口返回的单声道 16 位 PCM 会边接收边播放；如果接口使用 WAV 包装 PCM，也会逐段读取 WAV 头并立即播放音频内容，无需等待整段下载。

网页试听使用 Web Audio；安卓一起看使用 AudioTrack 的流式播放模式，且采用有界缓冲。缓冲已满时暂停接收下一段，避免把整条回复积压在内存。原有的音量、音频焦点、停止和账户退出处理继续有效。

安卓流式播放结束后，完整音频缓存在本机用于重播，不需要再次调用模型。中途停止会取消读取并丢弃未完成的音频；只有用户明确点击重试才重新合成。旧安卓壳或非 Qwen 流式接口沿用原来的完整音频方式。若服务端忽略流式参数、直接返回 MP3 等完整音频，则复用同一个请求的返回文件，不会自动发起第二次合成。

WAV 解析与裸 PCM 读取均由 `lib/tts-audio-stream.ts` 处理；Android 实际播放在 `CompanionPcmStream.kt`，新原生能力需要安装新版 APK。

1.0.2 起，安卓本地壳的 Qwen 请求先交给 App 自带的本机 Node 服务，再由该服务连接用户配置的语音接口。该路由仅在 Android 本机运行环境启用，受既有安装会话 Cookie 和账号门禁保护；网站部署不开放此代理。参考音频、密钥和文字仍只发往用户配置的接口，不经过额外云端中转。

取流保持标准 TLS 证书验证、240 秒总超时、有界响应、背压和取消处理，收到首段即可传递给播放器。它不重试合成，也不在流失败后自动再生成一次。网页端仍按原路径连接；手机连接失败、接收音频中断及服务端 HTTP 错误会分别呈现。此兼容改动不代表已经复现或确认所有手机网络故障的根因。
